## BeanTalk
커피 애호가들의 커뮤니티성 웹 애플리케이션

## 개발 인원
1인 개발

## 기술 스택
- typescript
- react
- vite
- tiptap
- kakao-maps
- react-hook-form
- tanstack-query
- scss
- cloudinary

## 배포 플랫폼
Vercel

## 배포 URL
https://bean-talk.vercel.app

## 설치
```
npm install
```

## 개발환경 실행
```
npm run dev
```

- tiptap과 kaka-maps를 이용한 사용자 친화적 WYSIWYG

- 유지보수를 위한 CoLocation 폴더 구조
